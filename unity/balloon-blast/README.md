# Balloon Blast Airsoft (Unity)

Procedural Unity 2022.3 project. GitHub Actions (`.github/workflows/unity-webgl.yml` on branch `unity-src`)
builds it to WebGL with `BuildScript.BuildWebGL` and publishes to `games/balloon-blast-unity/` on gh-pages.
The last build log is committed to `unity/logs/last-build.log`.
