Four Froggies 6.6 for Xbox (Dev Mode sideload)  -  build __TAG__ (__SHA__)
=========================================================================
This is the Unity 6 / 6.6 version (the same game as the "Four Froggies 6.6" arcade cabinet). It is a SEPARATE app
("Four Froggies 6.6", package SimilarizeFourFroggies66), so it installs NEXT TO the 2022.3 "Four Froggies" app - you
don't have to uninstall that one, and each keeps its own save.

What to download from this release (all on your PC):
  * __BUNDLE__                      <- the game
  * __DEPS__   <- dependency file(s) (x64)
  * FourFroggies66-__TAG__.cer      <- only needed if you ever install on a Windows PC (not needed for the Xbox)
  (FourFroggies66-UWP-__TAG__-package.zip has all of the above in one zip, if that's easier.)

The Xbox must already be in Developer Mode (Dev Home is the home screen).

1) On the Xbox, in Dev Home, open Remote Access settings (under "Remote Access" / "Remote Access Settings"):
   - turn on "Enable Xbox Device Portal"
   - turn on authentication and set a username and password (you'll type these on the PC).
   Dev Home then shows an address like  https://192.168.1.50:11443  - write it down.

2) On the PC (same home network), open that https://<xbox-ip>:11443 address in a browser.
   The browser warns about the certificate - that's expected for the Xbox's own self-made certificate:
   choose "Advanced" -> "Continue / Proceed". Sign in with the username and password from step 1.

3) In Device Portal, on the Home page under "My games & apps": click Add.
   - Choose the game file: __BUNDLE__ , click Next.
   - Dependencies: click "Choose file" and add __DEPS__ (add each one if there's more than one), click Next.
   - Click Install (Start). Wait for "Package successfully registered".
   If the Xbox says the dependency is already installed / a newer one is present, that's fine - just install the game.

   UPDATING from an older Four Froggies 6.6 build (ff-u6-uwp-...): either
     a) just install this bundle over it the same way (Device Portal -> Add); it replaces the old 6.6 one and your save stays, or
     b) if Device Portal refuses (e.g. "a higher version is already installed" / package conflict): first uninstall the old
        6.6 one - in Dev Home highlight Four Froggies 6.6, press the View button (two squares) -> Uninstall (or Device Portal ->
        My games & apps -> the "..." / Remove) - then install this one. Uninstalling clears the 6.6 save.
   The 2022.3 "Four Froggies" app (ff-uwp-...) is not touched by any of this.
   After installing, check the app type is still "Game" (step 4).

4) Back on the Xbox, in Dev Home, find "Four Froggies 6.6" in the list of games and apps.
   Before the first launch: highlight it, press the View button (two squares) -> "View details",
   and change the app type from "App" to "Game" (games get much more memory - leave it on App and it may close itself).
   Then press A to launch.

Playing: each Xbox controller is one froggy. A = join / start, D-pad = pick a character, B = leave / back.
Online rooms are only in the web version (similarize.com/games) for now; on Xbox it is local couch play.
Xbox One S profile (this build): 1280x720 render scaled to the TV, 30 fps cap, low quality tier locked (no stepping up),
lite grass / scans, no anti-aliasing, no post-processing, one short shadow range, half-resolution textures.
6.6 renderer on the console: Direct3D 11, URP Forward path (no Forward+ / SSAO / HDR), one 1024 shadow map.
New in this build (ffu73): James's trillion-story mech has a BRIDGE inside its head - R3 (press the right stick) while
piloting or riding it switches between the outside view and the bridge view.

On-screen checks (hold the buttons; a reminder shows for a few seconds after launch):
  * hold View 2 s        -> FPS counter (fps, frame ms, worst ms, render size, quality). Hold View 2 s again -> tries an
                            uncapped 60 fps mode; once more -> counter off (back to 30). Letting go of View may also switch
                            split / shared screen like a normal View press - tap View again to switch back.
  * hold View + Menu 2 s -> SOUND CHECK panel: re-opens the audio output, plays a short two-note test tone and shows what the
                            mixer is doing. While it is open, D-pad Right tries the next output mode (stereo 48 kHz, 7.1,
                            5.1, stereo 44.1 kHz, bigger buffer) with a test tone each time; the last one tried is kept for the
                            next launch. Hold View + Menu 2 s again to close (Menu may also open the help screen - press Menu
                            to close it).
  Please send back: the FPS numbers in the ranch and in a vehicle, and whether you hear the test tone / music, plus a phone photo
  of the SOUND CHECK panel if it stays silent.
  The full log is on the Xbox: Device Portal -> File explorer -> LocalAppData -> SimilarizeFourFroggies66_... -> TempState ->
  UnityPlayer.log (lines starting with FFXBOX).

If something goes wrong: in Device Portal open "Apps" or "Performance" to see whether it is running, and
"Diagnostics > Crash data" if it closes. Uninstall from Dev Home (View button -> Uninstall) or from Device Portal.
