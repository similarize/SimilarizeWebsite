# Four Froggies 3D is its own cabinet

`/games/four-froggies-3d/` is the standalone three.js ranch (monster truck, house, track). Do not replace that index.html with a redirect here.

Controllers: that page loads `../shared/gamepad.js` and maps Xbox the same way as this hub (A claim / interact, B release on the title screen, B/X hop, left stick). Couch: each pad claims one frog, one Cybertruck, the rest walk, leftover frog is AI.
